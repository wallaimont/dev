# Sistema de treino para entrevista de Desenvolvedor TOTVS Protheus

Este mini sistema em linha de comando ajuda você a praticar entrevistas para vagas Protheus com:

- Perguntas por tema (ADVPL, Protheus, Banco, Integrações e SQL)
- Autoavaliação com rubric simples (0-5)
- Plano de estudo automático com base nos pontos fracos

## Executar

```bash
node tools/protheus-interview/trainer.js
```

## Como funciona

1. Escolha quantas perguntas quer responder.
2. Leia a pergunta e escreva sua resposta.
3. Dê uma nota honesta para sua resposta (0-5).
4. Ao final, o sistema gera:
   - média geral
   - média por tema
   - plano de estudo recomendado

## Observação ética

O objetivo é **preparar** você para a entrevista, não fraudar processo seletivo.
